개인정보처리방침

시행일: 2026년 10월 20일 · 개정: 2026년 10월 21일

1. 처리하는 정보

  • 구글 로그인(OAuth) 후 발급되는 접근 토큰과 갱신 토큰
  • 연결한 유튜브 채널의 ID와 이름
  • 운영자가 만든 영상·음악 파일과 그 제목·설명
  • 운영자 본인이 올린 영상의 ID·공개 상태·조회수

2. 이용 목적

운영자 본인의 유튜브 채널에 영상을 올리고, 올린 영상의 공개 상태를 확인하고, 본인 영상의 제목·설명을 고치거나 다시 올리면서 생긴 예전 버전을 지우는 데에만 씁니다. 요청하는 권한: youtube.upload(올리기), youtube.readonly(내 채널·영상 확인), youtube.force-ssl(내 영상 수정·삭제).

3. 보관·삭제와 제공

  • 모든 정보는 운영자의 PC에만 저장되며 별도 서버로 보내지 않습니다.
  • 제3자에게 제공하거나 판매하지 않습니다.
  • YouTube API로 받은 정보(영상 상태 등)는 화면에 보여 주고 작업 기록을 맞추는 데에만 쓰며, 저장한 것은 30일 안에 새로 받거나 지웁니다.
  • 운영자가 연결을 끊으면 PC에 저장된 토큰을 지웁니다.

4. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 권한 철회

Google 계정의 서드파티 앱 접근 관리에서 언제든지 이 도구의 접근 권한을 해제할 수 있습니다.

Summary (English)

  • Data handled: OAuth access/refresh tokens, the connected channel's ID and name, the operator's own video/music files with their titles and descriptions, and the ID, privacy status and view counts of the operator's own uploads.
  • Purpose: upload to the operator's own channels, check upload status, edit titles/descriptions and delete older superseded versions of the operator's own videos. Scopes: youtube.upload, youtube.readonly, youtube.force-ssl.
  • Storage and deletion: everything stays on the operator's PC, nothing is sent to other servers, sold or shared. Data obtained from YouTube API Services is refreshed or deleted within 30 days; tokens are deleted when disconnected.
  • This tool uses YouTube API Services: the YouTube Terms of Service and the Google Privacy Policy apply. Access can be revoked at any time at Google Account permissions.
